# PDRA_XAI
The source code and dataset for our WIP paper called:

"Who’s Behind the Wheel Matters: Driver Monitoring feature analysis using explainable AI". The WIP paper will be available soon and we'll upload a pdf file here or a link when it's published. 

You can find the instructions about how to run the analysis in our jupyter notebook. We tried our best to make it intuitive and just change a few lines so you can replicate our analysis. If you have any questions or are curious about our work, please open an issue, or send us an email, so we can discuss further.
